# Dinosaur T-Rex Game

A lightweight, browser-based endless runner inspired by the classic Chrome Dino game.

## Play locally
Open `index.html` in a modern browser. No build step or external dependencies are required.

## Controls
- **Space / Up Arrow:** Jump
- **Down Arrow:** Duck
- **Tap/click:** Start or jump
- **Autopilot:** Optional local obstacle-dodging helper
- **Sound:** Toggle simple game sound effects

## Features
- Endless runner with cactus and flying-bird obstacles
- Increasing game speed
- Score and personal best saved in browser local storage
- Local top-score list
- Day/night visual variation
- Responsive layout for desktop and mobile

## GitHub Pages
To publish the game, open **Settings → Pages** in this repository, select **Deploy from a branch**, choose **main** and **/(root)**, then save. GitHub will provide the public Pages URL after deployment.
